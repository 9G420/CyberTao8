# Content Roadmap v0.1

This document tracks the first prototype content batches for Dice Beast Protocol.

## Batch 1 - Minimum Combat Prototype

Purpose:

- prove the board combat loop
- validate dice resource usage
- establish faction tone

Required content:

- `blade_shield_dog`
- one generic enemy grunt
- basic board rendering
- basic move resource consumption
- one basic attack action
- one self-buff skill
- one adjacent impact skill

## Batch 2 - Faction Contrast

Purpose:

- prove faction identity differences
- validate control and utility play

Planned additions:

- `hacker_fox`
- movement trick skill
- crest theft or crest disruption
- 2-3 pickup items

## Batch 3 - Tactical Board Variety

Purpose:

- test board items and lane pressure
- make turns feel less linear

Planned additions:

- temporary path booster pickups
- healing pickup
- attack booster pickup
- enemy positioning pressure

## First Three Pickup Concepts

- `patch_tea_cache`
- `overclock_bone`
- `glitch_snack_box`

## First Two Core Unit Archetypes

### Blade Shield Dog

- front line
- reactive defense
- shove and retaliate

### Hacker Fox

- mobility
- trick economy
- resource disruption
