# Mulerun 工作报告

**日期**: 2026-04-02
**版本**: v0.1.98
**分支**: `codex/dice-beast-protocol`

## 问题复现
- 2D 中键拖拽无反应（仅右键平移生效）
- 棋盘外视觉仍偏黑，和期望“背景区分”不一致

## 修复
- `BoardView.gd`
  - 输入兼容：新增 `Alt/Shift + 右键` 视角模式（中键失效时可替代）
  - 保留中键视角逻辑
  - `_draw_layer_grid()` 先铺背景底色，避免纯黑外场
  - `_draw_edge_vignette()` 暗角强度由 0.55 下调到 0.18

## 结果
- 2D 视角控制可用性提升（中键 + 兼容快捷）
- 棋盘外黑边明显减弱，背景分区更自然
