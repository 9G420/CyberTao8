## 建议下一步

进入第二阶段开发。推荐优先级：

1. **卡牌构筑成长**（最高优先）— 战斗胜利后选牌加入牌组，让每次遭遇有"收获感"
2. **更多敌方种类** — 当前只有 2 种遭遇敌方，需要 3~5 种以增加战斗变化
3. **棋盘随机生成** — 从固定布局升级为程序化棋盘，增加重玩性
4. **BFC 瘦身** — 剥离 debug spawn，降低维护成本
