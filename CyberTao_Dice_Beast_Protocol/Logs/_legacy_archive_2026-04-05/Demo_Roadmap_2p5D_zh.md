# CyberTao: Dice Beast Protocol
## 2.5D Demo 路线图（中文 — 方向更新版）

**更新时间**: 2026-03-29
**当前版本**: v0.1.21
**适用阶段**: 棋盘走位层基础完成，准备向双层玩法结构扩展

---

## 1. 当前阶段判断

v0.1.21 已完成棋盘走位层的基础底座：

- 掷骰 + 6 种 crest 资源池
- BFS 移动（含地形消耗权重）
- 基础攻击（含地形适性加成）
- 召唤铺路（SUMMON → 路径格 + 召唤单位）
- 高台/陷阱/路径 3 种地形
- 3 种单位地形适性
- 2 种即时道具
- 敌方 AI 意图广播 + 攻击预警
- 胜负判定 + 重新开始

项目已脱离"纯脚手架"阶段，进入：

**"棋盘走位层基础已成型，准备接入遭遇入口和卡牌战斗层"**

---

## 2. 总体目标

做出一个：

**"棋盘推进有策略、遭遇战斗有深度、视觉有赛博风格辨识度"的可试玩 Demo。**

Demo 应具备：
1. 双层玩法闭环（棋盘推进 → 遭遇 → 卡牌战斗 → 返回棋盘）
2. 足够顺手的操作体验
3. 明显优于纯平面原型的视觉表现
4. 适合录视频、给他人试玩

---

## 3. 推荐开发路线

### 第一阶段：双层玩法骨架
**目标：让"棋盘推进 + 遭遇战斗"的核心循环跑通**

必须完成：
1. 遭遇格原型入口（棋盘上踩格触发）
2. 遭遇暂停 + 战斗占位流程
3. 最小卡牌战斗原型（固定手牌/出牌/结算）
4. 战斗结算回到棋盘层

阶段完成标准：
- 能在棋盘上移动 → 踩到遭遇格 → 进入卡牌战斗 → 打完回来继续走
- 双层循环闭环成立

---

### 第二阶段：棋盘策略深化
**目标：让棋盘走位有真正的路线决策**

必须完成：
1. 格子事件化（恢复格/事件格/商店格）
2. 多条路线布局（不同风险/收益）
3. 棋盘走位影响战斗条件（地形buff带入战斗）
4. 战斗结果影响棋盘推进（奖励/惩罚）

阶段完成标准：
- 走位时有"走哪条路"的真实选择
- 棋盘层和卡牌层开始产生联动

---

### 第三阶段：卡牌战斗深化
**目标：让卡牌战斗有最小策略感和构筑成长**

必须完成：
1. 能量/费用系统
2. 手牌抽取机制（从牌组随机抽）
3. 2~3 种敌人行为模式
4. 获得新卡/升级机制

阶段完成标准：
- 战斗时有出牌选择
- 每场战斗结果不完全一样

---

### 第四阶段：2.5D 视觉升级
**目标：从"能玩"变成"看起来有味道"**

建议重点：
1. 棋盘倾斜透视风格
2. 格子带厚度、发光边缘、悬浮感
3. 单位从纯色块升级为立板式角色/伪 3D 精灵
4. 背景升级为"赛博道境战场"

---

### 第五阶段：仪式感演出
**目标：做出"游戏王DM骰子决斗"那种沉浸感**

优先级：
1. 骰子投掷演出（最能提升辨识度）
2. 召唤展开演出
3. 路径展开演出
4. 攻击命中特效增强
5. 镜头感/局部震动/屏幕反馈

---

### 第六阶段：Demo 包装
**目标：能拿给别人试玩并留下印象**

补齐：
1. 主菜单更像正式游戏
2. 教学提示更清楚
3. UI 风格统一
4. 首轮体验流畅

---

## 4. 推荐视觉路线

**2D 逻辑 + 2.5D 棋盘 + 伪 3D 单位 + 骰子演出**

原因：
1. 成本可控
2. 与当前项目基础兼容
3. 容易快速做出"看起来酷"的效果
4. 不会把开发复杂度炸开

---

## 5. 关键策略

正确顺序：

1. **双层玩法骨架**（遭遇入口 + 最小卡牌战斗）← 当前最优先
2. **棋盘策略深化**（格子事件化 + 路线决策）
3. **卡牌战斗深化**（能量/抽牌/构筑）
4. **2.5D 棋盘**
5. **骰子演出**

不要反过来。先把双层玩法跑通，再做视觉放大。

---

## 6. 一句话结论

**当前棋盘走位层基础已完成。下一步最关键的不是视觉升级，而是尽快让"棋盘推进 → 遭遇 → 卡牌战斗 → 返回棋盘"这条双层核心循环跑通。**
