CyberTao: Dice Beast Protocol is a hybrid tactical game combining dice-driven resource generation, board movement tactics, and card-based meta progression set in a CN meme + cyber furry aesthetic universe.
🎲

CORE MECHANICS

DICE RESOURCE SYSTEM

Each turn begins with a 3-dice roll generating resource crests: Summon, Move, Attack, Defend, Skill, and Trick. Crests fuel every action on the board.

BOARD MOVEMENT

Grid-based orthogonal movement with terrain interactions. Navigate path tiles, high ground, traps, and resource pickups with strategic positioning.

CARD BATTLE LAYER

Encounter triggers transition to a card battle phase. Draw hands, play cards, and resolve combat with energy-based cost systems.

UNIT SUMMONING

Spend Summon crests to deploy beast units onto the board. Each unit brings unique keywords, skills, and faction synergies to the battlefield.

TERRAIN SYSTEM

Normal, Path (+1 DEF), High Ground (+1 range, +2 move cost), Traps (-1 HP), Item pickups, Healing zones, and more cell types shape each encounter.

AI OPPONENTS

Enemy units operate with minimal turn phases and intent broadcasting. Encounter tiles trigger battles with escalating difficulty and boss encounters.

COMBAT SYSTEM

TURN STRUCTURE

Player Roll → Player Action → Enemy Roll → Enemy Action. Each phase resolves fully before the next begins.

DAMAGE FORMULA

max(1, ATK - DEF) — Simple, readable, minimum 1 damage always applies. Designed for fast prototype validation.

VICTORY CONDITIONS

Eliminate all enemy units to win. Lose if all player units fall. Simultaneous elimination results in a draw.

ATTACK TYPES

Melee: adjacent targets only (range 1). Ranged: beyond melee range. Normal attacks cost 1 Attack crest. Skills may consume Attack, Skill, or Trick crests.
